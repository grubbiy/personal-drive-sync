Privacy policy

Last updated: 13 November 2026

Personal Drive Sync is Vegard Laland's personal rclone configuration for synchronizing the owner's Google Drive with a local Documents folder. It is intended only for the owner's use.

Google data and its purpose

When authorized, rclone accesses Drive file contents and metadata, such as names, folders, sizes and modification times. It uses that access to list, download, upload, update and delete files as required for two-way synchronization. Files deleted in one location may also be deleted in the other during a sync.

Storage and access

The intended setup runs rclone on the owner's computer and transfers files between that computer and Google Drive. Downloaded files remain in the local Documents folder until removed. OAuth credentials and tokens are stored in the local rclone configuration; working files and logs may also be stored locally. Access to those local files depends on the computer's permissions and security.

Sharing and other uses

This setup is not intended to send Drive contents to this website, GitHub Pages, advertising services or an additional application server. Google data is used for the owner's file synchronization, not sold, used for advertising or used to train AI models. Existing sharing permissions on Google Drive continue to apply.

Stopping access and removing data

The owner can stop scheduled syncs and revoke the app's access in Google Account connections. Revoking access stops future authorized access but does not erase existing local copies or Drive files. Those copies and the local rclone configuration can be removed separately. Stop synchronization before deleting local copies that should remain on Drive.

This public website

These pages contain no analytics scripts, sign-in forms or application cookies. GitHub Pages hosts them and may process visitor connection information under the GitHub Privacy Statement. Google's handling of Drive data is described in the Google Privacy Policy.
